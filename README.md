# Gamepad Detection Input Test

This example demonstrates how a web browser can detect and read input from connected game controllers using the Web Gamepad API. It provides a simple diagnostic tool to check if your controller is recognized by the browser and if its buttons and axes are functioning correctly. This helps in troubleshooting 'controller not detected' issues by showing the programmatic detection and input status.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in a modern web browser (e.g., Chrome, Firefox, Edge).
3. Connect a gamepad (e.g., Xbox, PlayStation, or generic USB controller) to your computer and interact with it to see its status and inputs displayed on the page.
